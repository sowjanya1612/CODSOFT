Rock-Paper-Scissors Game

Description

This project is a Rock-Paper-Scissors game developed using Python.  
The user plays against the computer, which randomly selects rock, paper, or scissors.  
The program determines the winner based on standard game rules and keeps track of scores.

Objective
To create an interactive game using Python that demonstrates decision-making, loops, and random number generation.

Technologies Used

- Visual Studio Code
